
## The other SearchStack clients

- [`@searchstack/public-api`](https://github.com/searchstack-dev/searchstack-public-api) — TypeScript / JavaScript
- [`@searchstack/autocomplete`](https://github.com/searchstack-dev/searchstack-autocomplete) — drop-in browser search UI

A hosted [MCP server](https://mcp.searchstack.dev) exposes the same surface as tools, so Claude,
ChatGPT, Cursor or Copilot can search and manage your data directly. Every tool has a matching HTTP
endpoint; nothing is agent-only.
